## Pandas

  A biblioteca pandas é uma das mais utilizadas em Python para análise e manipulação de dados tabulares, como planilhas, arquivos CSV ou bases de dados. Ela permite ler, filtrar, agrupar, transformar e exportar dados de forma simples e eficiente, tornando-se uma ferramenta essencial em projetos de ciência de dados, estatística e automação de relatórios. Com pandas, você trabalha com estruturas chamadas DataFrame (tabelas) e Séries (colunas ou listas), podendo aplicar filtros condicionais, cálculos e até visualizar tendências antes mesmo de partir para gráficos. Seu uso é comum em contextos profissionais, acadêmicos e governamentais, especialmente quando se deseja extrair insights de dados organizados em colunas e linhas.
