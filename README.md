  <summary><strong>Primeiro exercíco: Introdução ao Python - Varíáveis</strong></summary><br />

  1- Use a função input() para solicitar ao usuário que digite seu nome, idade e
cidade onde mora. Armazene essas informações em variáveis chamadas nome,
idade e cidade. Imprima uma mensagem utilizando essas variáveis para mostrar
as informações fornecidas pelo usuário.

  2- Crie três variáveis chamadas nome, idade e altura. Atribua valores à essas
variáveis de forma que nome seja uma string com o seu nome, idade seja um
número inteiro com a sua idade e altura seja um número de ponto flutuante com
a sua altura em metros. Imprima na tela os valores de cada uma das variáveis.

  3- Crie quatro variáveis: uma do tipo string, uma do tipo inteiro, uma do tipo float
e uma do tipo booleano. Atribua valores apropriados a cada uma e, em seguida,
imprima o tipo de cada variável usando a função type(). Dica: Use type(variavel)
para obter o tipo da variável.

  4- Crie duas variáveis chamadas numero1 e numero2 e atribua a elas valores
inteiros informados pelo usuário do programa. Calcule a soma, subtração,
multiplicação e divisão desses dois números e armazene os resultados em
novas variáveis chamadas soma, subtracao, multiplicacao e divisao.
