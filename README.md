## 📌 Enunciado dos Exercícios

1) Fazer um algoritmo para preencher uma lista de 100 números.  
Utilize a função `random.randint(-100, 100)` para preencher a lista.  
Com a lista preenchida, compute conforme cada item abaixo:

- a) Imprima os números **positivos**  
- b) Imprima os números **negativos**  
- c) Imprima os números **pares**  
- d) Imprima os números **ímpares**  
- e) Imprima os números **múltiplos de 4**  
- f) Imprima o **maior número** da lista  
- g) Imprima o **menor número** da lista  
- h) Imprima a **média** dos números da lista  
- i) **Ordene** os elementos da lista em **ordem crescente**

---

2) Crie uma lista com os números de 1 a 10.  
Esses números devem ser **informados pelo usuário do programa**.

- a) Imprima o **terceiro elemento** da lista  
- b) Acesse o **último elemento** da lista  
- c) Modifique o **quinto elemento** da lista para o número `50`  
- d) Adicione o número `11` ao **final** da lista  
- e) Insira o número `0` no **início** da lista  
- f) Remova o **último elemento** da lista  
- g) Remova o elemento `50` da lista  
- h) Verifique se o número `5` está **na lista**

---

3) Crie uma nova lista que contenha os **quadrados dos números de 1 a 10**

4) Crie uma lista contendo **apenas os números pares de 1 a 20**
