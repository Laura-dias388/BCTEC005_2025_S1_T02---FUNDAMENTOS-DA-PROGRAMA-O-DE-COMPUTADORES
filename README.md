# 🧾 Exercício: Cálculo do Imposto de Renda | Python

Este exercício foi desenvolvido como parte da disciplina de **Fundamentos da Programação de Computadores**, do curso de **Bacharelado em Ciência e Tecnologia (BCT)** na **UNIFEI**.

O objetivo é criar um programa em **Python** que simule o cálculo do **Imposto de Renda** de uma pessoa física com base em faixas salariais pré-definidas.

# Enunciado

O Alex foi designado para desenvolver o sistema de Ana e outros cidadões de *Leão Bonzinho* utilizarão para calcular seus impostos de renda. O sistema deve solicitar ao usuário que insira sua renda anual e, com base no valor fornecido, calcular o imposto devido de acordo com as faixas de alíquotas fornecidas.

Requisitos:

# 🪪 1- Solicitação de credenciais para acessar o programa.

O sistema deverá simular o cadrastro salvo de dois usuários:
Login: Ana, senha: 12345
login: João, senha: 54321

# 2- Solicitação de renda Anual:
  ➡️ O sistema deve solicitar ao usuário que insira sua renda anual.

# 3- Solicitar ao usuário o tipo de cálculo que ele deseja, simplificado ou completo.

# 4- Solicitação de Despesas Dedutíveis:

  ➡️ O sistema deve soliccitar ao usuário que insira as despesas dedutíveis em categorias específicas.

# 5- Cálculo do Imposto:

  ➡️ O sistema deve calcular o imposto devido com base nas faixas de alíquotas fornecidas.

# 6- Mensagens:

  ➡️ O sistema deve exibir a renda anual e o imposto devido a ser pago ou restituído para o usuário.

# 7- Implementação:

  ➡️ Utilize estruturas de decisão para implemntar a lógica do sistema.

# Reduções de Imposto

  Além das opções de Imposto Simplificado e Completo, os cidadões de *Leão Bonzinho* podem reduzir o valor do imposto a ser pago declarando despesas em determinadas áreas. As seguintes despesas são dedutíveis:

  🚑 **Despesas Médicas:** reduz até 5% do imposto. Ou seja, o impsoto a ser pago pode ser reduzido ate 5% do seu valor por meio dos custos com despesas médicas.

  🏫 **Despesas Escolares:** reduz ate 10% do imposto. Ou seja, o imposto a ser pago pode ser reduzido até 10% do seu valor por meio dos custos com despesas médicas.

  📚 **Despesas com livros:** reduz ate 2% do imposto. Ou seja, o imposto a ser pago pode ser reduzido até 2% do seu valor por meio dos custos com despesas com livros.

  🧳 **Despesas com Viagens:** reduz ate 30% do imposto. Ou seja, o imposto a ser pago pode ser reduzido até 30% do seu valor por meio dos custos com despesas para viagens.

# Imposto Simplificado:

  ➡️ No imposto simplificado, é aplicado um desconto no imposto de 9% sobre a renda anual, essa modalidade é permitida para rendas anuais de até R$ 45.012,60.

  ➡️ No imposto completo, não há descontos, o imposto é calculado diretamente sobre a renda anual bruta utilizando as faixas de alícotas.

# Faixas de alíquotas:

  ➡️ Até R$ 22.847,76: Isento

  ➡️ De R$ 22.847,77 a R$ 33.919,80: 7,5%

  ➡️ De R$ 33.919,81 a R$ 45.012,60: 15%

  ➡️ De R$ 45.012,61 a R$ 55.976,16: 22,5%
  
  ➡️ Acima de R$ 55.976,16: 27,5%
